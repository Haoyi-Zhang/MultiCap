# Reference integrity evidence

This directory records a fresh registry cross-check and every citation context. Crossref/DOI and OpenAlex metadata are used to confirm identity and to expose retraction flags; citation counts are retained only as metadata and are not treated as a quality score. `citation_context_ledger.csv` maps every in-text occurrence to its section and local context so that semantic appropriateness is auditable. Network snapshots are evidence for this release, not a runtime dependency of the scientific reproduction.
